20260303一点碎碎念

发表于 2026-03-05 分类于 杂项 阅读次数：
本文字数： 815 阅读时长 ≈ 3 分钟

算是对4-2的规划和本科生涯的总结吧(大概x.

嗯...首先恭喜自己获得了offer, 然后理所当然的摆了接近半年(x.

一路走来其实是有不少遗憾的, 想找借口也有很多, 比如新冠降智啦, 某带专周所周知的课程设计啦, 总是忍不住出勤啦(awmc)什么的. 但归根结底还是自己的问题, 能力和沉淀都不够, 最后的结果也是咎由自取罢了.

不过好在运气不错, 也算是即将结束自己的读书生涯, 成为平凡社畜的一员打赛博螺丝了. 想即此多少有点感伤, 大学是有时间没钱, 以后就要有钱没时间咯(也可能是又没时间又没钱)

事已至此, 拷打曾经的自己也是无济于事了. 该想想迫在眉睫的事情了, 比如说毕业论文导师(学院没有双选表, 没有兜底分配是什么鬼啊, 纯纯草台班子, 两百个学生几十个导师我怎么知道哪些导师还有名额 /续标识), 论文开题和做实验写论文, 现在感觉大概率要做AI相关的学术垃圾, 但还锝先学基础知识, 真是头疼, 为什么不能搞毕设毕业啊喂! (没招了投降了, 凑带专你赢了)

哎哎纯发牢骚, 就业相关的基础也不扎实, 还要抽空学数据库, 学开发框架, 形成记录文档, 自己想做的事情还要好多, 哎哎. 总之简单列举一下自己想做的事情好了.

短期计划

  • 确定毕业论文导师和开题选项

学期计划

  • 恶补机器学习基础知识
  • 学习数据库
  • 学习开发框架(可选)
  • 毕业论文相关工作(阅读论文, coding实验, 论文编写)
  • 完成一些简单的项目(半年没怎么碰代码了, 需要找回手感)

学期课余计划(希望至少能做一点吧)

  • 手绘学习提上日程, 鸽了好久的百张临摹无论如何也要启动了
  • 重部署qq bot, 更新napcat和astrbot框架, 理解并记录框架结构, 如有条件重构astr框架
  • 阅读书籍, 至少把手上的四本书看完
  • 部署手上的树莓派, 作为toy backend为云服务器提供简单的算力支持(还需要重修计网来完成桥接)
  • 学习舞萌dx自制, 小目标是写三张谱(感觉大概率是官谱高级抄手)

可能是存在于幻想中的计划

  • 学习游戏开发, 复现一些简单的经典游戏, 起草处女作策划案
  • 重构迁移博客和个人网站(hexo在当下感觉稍微有点不方便了, 速度较慢且功能不够丰富, 不过说到底还是自己菜了没办法开发x), 迁移后可以做一点神秘小网站
  • 学习日语, 成为日语领域大神x
  • 尝试写小说, 构建世界观并写一些oc小故事
  • 学习乐器(可能是电子钢琴), 学习编曲作曲
